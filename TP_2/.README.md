# Mini compte rendu

## Commandes de vérification

J'ai utilisé les commandes suivantes :

- kubectl get nodes
- kubectl get pods -n tp-minikube
- kubectl get svc -n tp-minikube
- kubectl describe pod -n tp-minikube -l app=web-nginx
- kubectl rollout status -n tp-minikube deployment/web-nginx

## Comment le service a été exposé

J'ai créé un service de type ClusterIP nommé web-nginx-svc, relié aux Pods avec le label app: web-nginx.

## Difficultés rencontrées

- Minikube ne fonctionnait pas correctement sur ma machine, donc je n’ai pas pu valider le déploiement comme prévu au début.
- J’ai aussi galéré à mettre en place le ReplicaSet. Au départ, je pensais qu’il fallait le créer ou le gérer à la main, puis j’ai fini par comprendre dans la documentation qu’il est piloté automatiquement par le Deployment.
